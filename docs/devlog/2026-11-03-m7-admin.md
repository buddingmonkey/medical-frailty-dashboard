## Step 1: backup download and restore (13:35–14:00 builder; lead merge to 14:25)
- `GET /api/admin/backup` streams a **zip** (`fflate` 0.8.3) with one JSON file, format 2.
  It holds every state-data table, read 500 rows at a time. It leaves out the reference,
  derived and FTS tables, and says so in a `notes` field. A test fails if a new table is in
  neither list. R2 keys stay out, because `docs/security.md` says they never leave the Worker.
- Seed (51 states): 13,735 rows, a 5.4 MB JSON zipped to 237 kB in ~0.3 s, 44 queries.
- `/admin/restore` takes the zip or a per-publish `.json` (format 1). The admin picks one
  state and version, and it comes back as a **draft** through the existing draft API, then
  checks and publish. A missing source PDF is kept as a citation ("file not available").
  Mappings come back only when ticked, after a diff.
- Zip-bomb guard: one top-level `.json` only, and inflation stops past 50 MB. Without the cap,
  `fflate`'s `unzipSync` would have inflated a bomb in full; inflating in 16 KB slices bounds
  memory.
