## Goal

Set up `apps/web` (Vite, Vue 3, Vue Router, Tailwind v4, TanStack Query) with a placeholder
page, and set the design tokens (colour, type, spacing) once, with the project lead's approval.

## What happened

1. The project lead gave a fixed prompt: plan first, pin exact versions checked online,
   respect the 3-day package-age guard, show the palette before applying it.
2. The AI checked versions on the npm registry and proposed a plan, a neutral blue palette
   with contrast ratios, and four questions (palette, fonts, dark mode, routing style).
3. The project lead asked for a swatch page **based on the Georgetown CCF site's branding**,
   fonts we are legally allowed to use, dark mode plus "system" before launch, and file-based
   routing.
4. The AI read CCF's stylesheet for its colour presets and font kit, built light and dark
   token sets from them, checked every text pair for WCAG contrast, and published a private
   swatch page with a live System/Light/Dark switch and a sample code table.
5. The project lead chose Source Sans 3 for body text, no serif for now, and said the site is
   not officially a CCF site (branding may come later).
6. The AI built the app, got lint, `vue-tsc`, format check and the production build passing,
   then confirmed the checks fail on a deliberately bad component (`any`, `v-html`, a type
   error and an unknown template variable).

## Corrections and surprises

- **`unplugin-vue-router` is deprecated**: file-based routing moved into Vue Router 5. The
  `vue-development` skill's routing guide still shows the old `vue-router/auto` imports.
- **Licensed fonts.** "Use their branding" could have meant copying CCF's Adobe Fonts kit
  link, which would break their licence. The AI flagged it and chose free look-alikes.
- **CCF gold fails as text** on white (3.4:1), so it is limited to rules and accents.
- **Typed lint and `.vue` imports.** typescript-eslint could not type `import App from
  './App.vue'` in `main.ts` until a small `*.vue` module declaration was added.
- **`vue/multi-word-component-names`** flagged the route file `(home).vue`; the rule is off
  for `src/pages/` only, where the file name is the route.
- `vue-tsc` 3.3.14 cleared the 3-day guard by under three hours.

## What a non-technical builder should take from this

1. Ask for a visual preview (a swatch page) before the AI applies colours and fonts. It is
   much easier to judge than a table of hex codes.
2. "Make it look like X" is fine for colours, but fonts and logos are licensed. Ask the AI
   which ones you are allowed to use.
3. Check contrast for every colour pairing, in light and dark mode, before building.
