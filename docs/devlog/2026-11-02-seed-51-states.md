# 2026-11-02: Seed data for all 51 states

**Milestone:** after M5 (preview data)  •  **People:** project lead  •  **AI:** Claude Code, Opus lead and one builder in a worktree (the first under the new workflow)

Start 23:22 CST, end 23:45 CST (`date`).

## Why
"I want seed data for all 50+1 states with codes for most of them … so that I can evaluate
the design of the page. The compare page is still empty." Four states can't show a matrix,
a tile map or a set of similar states.

## What happened
1. The four real states are now sampled at 300 entries each. The other 47 states are
   synthetic:
   - 40 have published lists, 4 are announced and 3 have none.
   - Each list is built from the four real lists' code patterns. It never takes their
     published text, so `description_published` is NULL.
   - Each list has a seeded PRNG keyed on the state, and each category aims at a band (high,
     mid, low or none). Category names, tiers, qualification rules and approved mappings vary
     by state.
   - Each synthetic state's source document is titled "Synthetic test list (seed data, not a
     real state list)".
2. The builder added 3-character category heads as candidate entries, which cut the file
   from 8.6 MB to 2.8 MB.
3. Measured on a local copy (12,153 entries):
   - The rebuild took 10.9 s and produced 12,369 placements and 946 pairs.
   - Of the matrix cells, 184 are high, 277 mid, 252 low and 123 none; 357 are not reviewed.
   - Blindness and IDD never reach high, because the real lists cover only 34% and 52% of
     those categories' codes.
4. Production's starter categories are still drafts with no full code lists. The generator
   therefore computes each category's code list with a read-only query.
5. **Workflow note:** this builder started from a HEAD that didn't have
   `scripts/builder-setup.sh` yet, so it did the setup steps by hand. It also ran
   `check:full` against the brief. It had no clash this time, but the other builder was
   running.
